# The Platform - 個体群ベース生物学的モデル

映画「The Platform」にインスパイアされた、限定された食料条件下での人間性進化シミュレーション

---

## 概要

このプロジェクトは、限定的な食料状況下で人間のコミュニティがどのように進化するかを探索する個体群ベースモデルです。各住民には独自の食料要件があり、異なる食料供給量の環境下での適応を観察します。

---

## 人間性の定義

**人間性レベル** = `満腹必要量 - 最小必要量`

各住民には以下の特性があります：
- `food_require`：生存に最小限必要な食料量
- `food_greedy`：完全に満腹になるために必要な食料量
- `alive_flag`：生存状態フラグ（1 = 生存、0 = 死亡）

人間性は「生存に必須の食料量を超えて、どれだけ食べられるか」の容量を表しており、より大きな値は個体の適応力の高さを示唆します。

## 設定ファイル（setting.py）

`setting.py`で以下のパラメータを調整できます：

```python
floors = 1000                          # 実験ビルの階数（住民数）
experimental_food_range = range(0, 100, 10)  # テストする食料量の範囲
number_of_rounds = 100                 # 各実験でのシミュレーション周期数
```

## アルゴリズム

シミュレーションは以下の流れで実行されます：

### 1. 初期化
- 指定された数の住民がランダムな食料要件とともに作成されます

### 2. シミュレーション周期（各周期で実行）

1. **食料配分** (`distribute_food`)：
   - 利用可能な食料を住民に順番に配分
   - 各住民は以下の優先度で食べます：
     - 満腹までの量 ≤ 残り食料 → 満腹まで食べる
     - 最小必要量 ≤ 残り食料 → 最小限食べる
     - 上記以外 → 死亡（alive_flag = 0）

2. **住民置き換え** (`replace_dead_inhabitants`)：
   - 死亡した住民を新しい住民で置き換え

3. **シャッフル** (`shuffle_inhabitants`)：
   - 住民の順序をランダム化（次周期の食料配分に影響）

### 3. 人間性測定
各実験後、すべての住民の人間性レベルを計算し、平均値を記録します。

---

## 出力

- **コンソール出力**: 各食料量と周期ごとの平均人間性レベル
- **ヒストグラム**: 全実験結果の人間性レベル分布
- **実行時間**: シミュレーション所要時間（日数）

---

## コアモジュール（func.py）

### ThePlatform クラス

| メソッド | 説明 |
|---------|------|
| `create_inhabitant()` | ランダムな食料要件を持つ住民を生成 |
| `create_hole(depth)` | 指定数の住民でビルを構成 |
| `distribute_food(hole, amount)` | 食料を住民に配分 |
| `replace_dead_inhabitants(hole)` | 死亡した住民を置き換え |
| `shuffle_inhabitants(inhabitants)` | 住民の順序をランダム化 |
| `calculate_humanity_levels(hole)` | 全住民の人間性レベルを計算 |
| `simulate_period(hole, food, rounds)` | 複数周期のシミュレーション実行 |
| `plot_histogram(data, x_limit)` | 結果をヒストグラムで可視化 |

### UniversalFunc クラス（ユーティリティ）

| メソッド | 説明 |
|---------|------|
| `calculate_mean(data)` | データの平均値を計算 |
| `calculate_mean_and_append(data)` | 平均値を計算してリストで返す |
| `start_timer()` | タイマーを開始 |
| `end_timer(start_time)` | タイマーを終了し経過時間を表示 |

## 実験内容

本モデルでは複数の食料量レベルでシミュレーションを実行し、以下を調査します：

- 食料の希少性が人間性に与える影響
- 環境ストレス下での適応メカニズム
- 集団内の人間性レベルの分布変化
- 異なる食料供給条件下での個体群動態
